# ZHCASH OnlyFans Edition

Подарок от разработчиков ZHCASH. Отдельная добровольно устанавливаемая
экспериментальная macOS-версия полной Qt-ноды, не замена основного релиза.

## Оформление

Графитовый интерфейс, светлые иконки, масштабирование шрифтов в настройках,
серые QR-коды, улучшенная русская локализация и размеры полей ABI/байткода.
Заставка длится минимум 10 секунд: символы собираются в рисунок, логотип
пульсирует. Таймер обновления 16 мс; фактический FPS зависит от оборудования.
Нативные три кнопки macOS видны при развёрнутом запуске окна.
Синяя неоновая иконка имеет белую середину; оригинальные красные изображения
сохранены в `src/qt/res/icons/original-red/`.
Заставка содержит художественный ASCII-рисунок обнажённой взрослой фигуры.

## Совместимость и установка

Текущий DMG предназначен для Apple Silicon, macOS 26.0+. Intel не поддерживается.
Приложение подписано ad-hoc, без Developer ID и нотарификации Apple.
Откройте DMG и скопируйте `ZHCASH OnlyFans Edition.app` в Applications.
Приложение использует стандартный каталог данных ZHCASH:
`~/Library/Application Support/ZHCASH`; отдельное имя приложения не создаёт
отдельный кошелёк или блокчейн. Перед использованием существующего кошелька
сохраните его резервную копию и завершите другую ноду, использующую этот каталог.

## Сборка

Используется тот же настроенный ARM64 depends/Qt build, что у Evolution.
После изменения configure.ac выполните autoreconf -fi и configure по инструкции
основной macOS-сборки. Затем:

```sh
ZHC_DEPENDS_PREFIX=/absolute/path/to/depends/aarch64-apple-darwin \
  bash contrib/devtools/package-onlyfans-macos.sh
```

Выходной каталог: `release-onlyfans-macos` (или `ZHC_RELEASE_DIR`).
Скрипт создаёт приложение, DMG, SHA256SUMS и SOURCE_COMMIT.

## Публикация и проверки

Ветка `macos_onlyfans_version`. GitHub release обязан иметь `prerelease=true`
и `make_latest=false`. Основной `/releases/latest` не изменяется.
Сборка и проверка ad-hoc подписи обязательны. Smoke-проверка выполняется
на изолированном regtest: запуск, чтение RPC и штатное завершение.
Это не полный аудит консенсуса или совместимости всех старых кошельков.

Имя издания не означает связи с платформой OnlyFans.
